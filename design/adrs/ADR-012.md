> **Superseded by `adr:ADR-024.md`.** The "self-hosted by default" framing protected
> a guarantee (air-gap) that was never true of the web path, and hard-wired one
> fetch vendor. The durable clauses below — no telemetry ever, web ingestion strictly
> opt-in, no remote inference by default — are restated and remain in force.

## Context
`air-gapped-runtime.md` currently states "100% air-gapped runtime with zero telemetry or remote API calls" and "no outbound network calls... or external cloud LLM dependencies." Taken literally, this contradicts `web-and-nonlocal-content.md` and ADR-008, which require fetching web URIs (via Firecrawl or a headless fetcher) — an operation that inherently makes outbound network calls to sites the user asks to index.

## Decision
The air-gap guarantee is scoped to **default behavior and data handling**, not to an absolute prohibition on any network call ever:
1. **Local-by-default:** With no web URIs registered, `prag` makes zero outbound network calls. Embeddings, parsing, and storage run entirely with local models (ADR-006) and local disk (ADR-001/ADR-002).
2. **Opt-in web ingestion:** Outbound network calls only occur for URIs the user explicitly grants via `prag watch https://...`. No background telemetry, analytics, or usage reporting is ever sent regardless of configuration.
3. **Firecrawl is self-hostable, not a mandated SaaS dependency:** The web-fetch backend (Firecrawl or a lightweight headless fetcher) must support pointing at a self-hosted instance via configuration (e.g. `PRAG_FIRECRAWL_URL`). The hosted firecrawl.dev API is an optional convenience, not a requirement — a fully local deployment is achievable using a self-hosted Firecrawl instance or the plain headless-fetcher fallback.
4. **Embedding stays local by default:** `PRAG_EMBEDDING_DEVICE`/`PRAG_EMBEDDING_MODEL` default to the local ONNX runtime (ADR-006). Nothing in the default configuration sends text to a remote inference API.

## Consequences
- `air-gapped-runtime.md` and `web-and-nonlocal-content.md` are updated to reference this ADR and use "self-hosted by default" language instead of an absolute "zero outbound calls" claim.
- Any future remote-inference or hosted-SaaS integration must be explicitly opt-in and documented as such; it cannot be silently defaulted on.
